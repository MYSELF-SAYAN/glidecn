# CLI Reference

The official `glidecn-cli` tool scaffolds transition pipelines, downloads transitions, updates installed components, and auto-wires Framer Motion into your project with zero runtime dependencies.

```bash
# Initialize GlideCN in a project
npx glidecn-cli init

# Add transitions
npx glidecn-cli add cube circular-portal

# Update core engine and installed transitions
npx glidecn-cli update
```
