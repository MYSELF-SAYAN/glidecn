Morphy is an open-source movement built for and by the community. We value minimal friction, beautiful code, and high-quality user experiences.

## Core Philosophy

- **Simplicity First**: Code should read like prose. Avoid over-engineering.
- **Aesthetic Excellence**: If it touches the DOM, it must look and feel premium.
- **Performant by Default**: GPU-acceleration and zero layout shifts are non-negotiable.

## Development Setup

1. **Clone the repository**
```bash
git clone https://github.com/morphyjs/morphy.git
cd morphy
```

2. **Install dependencies**
We use `pnpm` for fast, deterministic package management.
```bash
pnpm install
```

3. **Start the development server**
```bash
pnpm run dev
```

## Adding a Transition

All transitions are powered by Framer Motion. To add a new transition:

1. Create your component in `components/morphy/transitions`.
2. Register the metadata in `lib/transition-catalog.ts`.
3. Test locally in the Playground (`/playground`).

## Submitting a Pull Request

- Keep PRs scoped and focused.
- Prefix your commits (e.g., `feat:`, `fix:`, `chore:`).
- Include screenshots or videos for UI changes.

We review PRs weekly. Join us in building the most elegant transition library on the web.
