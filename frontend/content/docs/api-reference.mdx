GlideCN provides a clean, minimalistic API surface. You only need to interact with two main components and one hook to build incredibly rich transitions.

## `<GlideCNProvider>`

The `GlideCNProvider` is the root coordinator. It intercepts routing events, manages the outgoing freeze-frame snapshots, and handles the dual-frame crossfade mounting logic.

<Callout type="info">
  **Placement Strategy**: Place this as high in your component tree as possible (e.g., inside `app/layout.tsx`).
</Callout>

## `<Page>`

The `<Page>` component represents an animatable route segment. You should wrap the top-level content of every individual page with this component.

## `useGlide()`

A custom React hook that allows you to programmatically read and modify the active transition configuration at runtime.

### Returned Object

<TypeTable
  type={{
    currentTransition: {
      description: 'The currently active transition name.',
      type: 'string',
    },
    transitionDefinition: {
      description: 'The resolved transition definition object.',
      type: 'TransitionDefinition | null',
    },
    config: {
      description: 'The merged configuration object (defaults + overrides).',
      type: 'Required<TransitionConfig>',
    },
    animationState: {
      description: 'The current lifecycle state of the page transition.',
      type: '"idle" | "entering" | "exiting" | "complete"',
    },
    reducedMotion: {
      description: 'Whether reduced motion is currently active.',
      type: 'boolean',
    },
    setTransition: {
      description: 'Set the active transition by name.',
      type: '(name: string) => void',
    },
    setConfig: {
      description: 'Override config for the current transition.',
      type: '(config: TransitionConfig) => void',
    },
  }}
/>

### Example Usage

<Tabs items={['Next.js (App)', 'Next.js (Pages)', 'Vite / React', 'Remix']}>

<Tab value="Next.js (App)">
```tsx title="components/settings-panel.tsx"
'use client';

import { useGlide } from '@/components/glidecn';

export function SettingsPanel() {
  const { currentTransition, setTransition, setConfig } = useGlide();

  return (
    <div className="flex gap-4">
      <button onClick={() => setTransition('cube')}>
        Use 3D Cube (Current: {currentTransition})
      </button>

      <button onClick={() => setConfig({ duration: 1.2 })}>
        Slow Down (1.2s)
      </button>
    </div>
  );
}
```
</Tab>
