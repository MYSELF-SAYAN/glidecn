MorphyJS provides a clean, minimalistic API surface. You only need to interact with two main components and one hook to build incredibly rich transitions.

---

## `<MorphyProvider>`

The `MorphyProvider` is the root coordinator. It intercepts routing events, manages the outgoing freeze-frame snapshots, and handles the dual-frame crossfade mounting logic.

You should place this as high in your component tree as possible (e.g., inside `app/layout.tsx` or `pages/_app.tsx`).

### Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | **Required** | Your application layout/content. |
| `defaultTransition` | `string` | `"fade"` | The default transition animation used if a `<Page>` does not specify its own `transition` prop. |
| `defaultDuration` | `number` | `0.5` | The default duration (in seconds) for animations. |
| `className` | `string` | `undefined` | Optional CSS classes to apply to the provider's wrapper container. |
| `style` | `React.CSSProperties` | `undefined` | Optional inline styles for the provider wrapper. |

> [!TIP]
> **Why do we need a provider?** MorphyJS needs a fixed boundary to take a visual snapshot of the "outgoing" page when a route changes. The provider maintains this boundary so layout shifts don't ruin the transition.

---

## `<Page>`

The `<Page>` component represents an animatable route segment. You should wrap the top-level content of every individual page with this component.

### Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | **Required** | The content of your page. |
| `transition` | `string` | *Inherits* | Overrides the `defaultTransition` set in the provider. Choose from any of the 33+ shaders (e.g., `"cube"`, `"circular-portal"`, `"origami-unfold"`). |
| `duration` | `number` | *Inherits* | Overrides the default duration for this specific page. |
| `direction` | `"in" \| "out" \| "left" \| "right" \| "up" \| "down"` | `undefined` | Defines the directional flow of the animation (applicable for spatial and kinetic shaders like `slide` or `cube`). |
| `className` | `string` | `undefined` | CSS classes to apply to the page container. |
| `style` | `React.CSSProperties` | `undefined` | Inline styles for the page container. |

> [!IMPORTANT]  
> If you omit `transition` or `duration` on a `<Page>`, it will automatically inherit the global defaults configured in your `<MorphyProvider>`.

## `useMorphy()`

A custom React hook that allows you to programmatically read and modify the active transition configuration at runtime.

### Returned Object

| Property | Type | Description |
| :--- | :--- | :--- |
| `currentTransition` | `string` | The currently active transition ID. |
| `config` | `object` | The current global configuration object containing `duration` and `direction`. |
| `setTransition` | `(id: string) => void` | Programmatically update the global transition type. |
| `setConfig` | `(cfg: Partial<Config>) => void` | Update the global transition configuration (e.g., duration, direction). |

### Example Usage

```tsx title="components/settings-panel.tsx"
'use client';

import { useMorphy } from '@/components/morphy';

export function SettingsPanel() {
  const { currentTransition, setTransition, setConfig } = useMorphy();

  return (
    <div className="flex gap-4">
      <button onClick={() => setTransition('cube')}>
        Use 3D Cube (Current: {currentTransition})
      </button>

      <button onClick={() => setConfig({ duration: 1.2 })}>
        Slow Down (1.2s)
      </button>
    </div>
  );
}
```
