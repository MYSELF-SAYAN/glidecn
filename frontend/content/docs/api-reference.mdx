GlideCN is engineered with a clean, minimal API surface designed for maximum control with minimal boilerplate. Explore the dedicated reference pages for every primitive below.

---

## Core Components

### [`<GlideCNProvider>`](/docs/api/provider)
The root context coordinator. Injects global transition configuration, sets baseline fallback transitions, manages default duration and easing curves, and auto-detects user motion preferences.
- **[View `<GlideCNProvider>` Reference →](/docs/api/provider)**

### [`<GlideCN>`](/docs/api/glidecn)
The framework-specific router adapter and transition coordinator. Orchestrates Framer Motion's `AnimatePresence`, freezes the exiting page router context to prevent white flashes, and manages automatic scroll restoration.
- **[View `<GlideCN>` Reference →](/docs/api/glidecn)**

### [`<Page>`](/docs/api/page)
The route-level segment component. Wrap each individual page or view to apply custom transitions, per-page duration and easing overrides, directional flow axes, and GPU acceleration hints.
- **[View `<Page>` Reference →](/docs/api/page)**

## Context Hooks

### [`useGlide()`](/docs/api/hooks/use-glide)
Primary controller hook exposing the active transition name, merged configuration options, lifecycle animation state (`"idle" | "entering" | "exiting" | "complete"`), reduced motion status, and mutators (`setTransition`, `setConfig`).
- **[View `useGlide()` Reference →](/docs/api/hooks/use-glide)**

### [`useTransitionConfig()`](/docs/api/hooks/use-transition-config)
Lightweight convenience hook returning `{ config, setConfig }` for quick duration, easing, or direction manipulation without full state overhead.
- **[View `useTransitionConfig()` Reference →](/docs/api/hooks/use-transition-config)**

### [`useAnimationState()`](/docs/api/hooks/use-animation-state)
Lifecycle monitor hook returning the active transition phase (`"idle" | "entering" | "exiting" | "complete"`). Perfect for navigation guards, loading bars, and status indicators.
- **[View `useAnimationState()` Reference →](/docs/api/hooks/use-animation-state)**
