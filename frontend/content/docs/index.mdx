**MorphyJS** is an open-source page transition engine designed for Next.js App Router and React. It delivers 33+ hardware-accelerated 3D shaders, portals, origami folds, and fluid masks with copy-paste developer experience.

## Why MorphyJS?

Traditional page transitions in React often suffer from layout shifts, flashing unmounted content, or complex router locking hacks. MorphyJS solves this through a synchronized dual-frame rendering architecture.

  <Card title="60 FPS Hardware Acceleration">

## 30-Second Quickstart

<Steps>
<Step>

### Wrap Root Layout

Wrap your root layout with `<MorphyProvider>`:

```tsx title="app/layout.tsx"
import { MorphyProvider } from '@/components/morphy';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <MorphyProvider defaultTransition="cube">
          {children}
        </MorphyProvider>
      </body>
    </html>
  );
}
```

</Step>
<Step>

### Define Page Transitions

Wrap your page routes with `<Page>` and assign any transition:

```tsx title="app/contact/page.tsx"
import { Page } from '@/components/morphy';

export default function ContactPage() {
  return (
    <Page transition="circular-portal" duration={0.7}>
      <main className="p-8">
        <h1>Contact Us</h1>
        <p>This page reveals with a circular iris portal.</p>
      </main>
    </Page>
  );
}
```

</Step>
</Steps>

## Architecture

MorphyJS synchronizes with the Next.js navigation lifecycle to manage concurrent mounting of outgoing and incoming route segments.

1. **Global MorphyProvider**: Intercepts navigations and orchestrates the timeline.
2. **Frozen Router Context**: Captures the outgoing route segment in a frozen visual boundary, preventing it from updating with new URL params or unmounting mid-animation.
3. **Pluggable Shader Registry**: Every transition is an isolated `TransitionDefinition` containing pure Framer Motion variants. You only bundle what you use.
