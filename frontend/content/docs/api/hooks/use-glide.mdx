---
title: "useGlide()"
description: "The primary React hook to inspect, orchestrate, and dynamically update transition configurations at runtime."
---

`useGlide()` is the core hook for interacting with the GlideCN transition state. It provides direct access to the active transition name, merged configuration options, animation lifecycle status, reduced-motion preferences, and runtime mutators (`setTransition`, `setConfig`).

Must be used inside components rendered under [`<GlideCNProvider>`](/docs/api/provider).

---

## Import

```tsx
import { useGlide } from '@/components/glidecn';
```

---

## Signature & Return Object

```tsx
const {
  currentTransition,
  setTransition,
  config,
  setConfig,
  animationState,
  reducedMotion,
  transitionDefinition,
} = useGlide();
```

---

## Return Properties Reference

| Property | Type | Description |
| :--- | :--- | :--- |
| [`currentTransition`](#currenttransition) | `string` | The machine name of the currently active transition. |
| [`setTransition`](#settransition) | `(name: string) => void` | Function to dynamically switch the active transition. |
| [`config`](#config) | `Required<TransitionConfig>` | The fully resolved transition configuration object. |
| [`setConfig`](#setconfig) | `(config: TransitionConfig) => void` | Function to override transition timing, easing, or direction. |
| [`animationState`](#animationstate) | `"idle" \| "entering" \| "exiting" \| "complete"` | Current lifecycle phase of the page animation. |
| [`reducedMotion`](#reducedmotion) | `boolean` | Whether reduced-motion mode is currently active. |
| [`transitionDefinition`](#transitiondefinition) | `TransitionDefinition \| null` | The registered definition object and metadata. |

## Detailed Properties & Examples

### `currentTransition`

A string containing the active transition identifier (e.g. `"fade"`, `"slide"`, `"liquid-morph"`).

```tsx
export function TransitionBadge() {
  const { currentTransition } = useGlide();
  return <div className="badge font-mono">Active: {currentTransition}</div>;
}
```

---

### `setTransition(name)`

Imperatively sets the active transition before or during navigation. Useful for contextual buttons (e.g. triggering an explosion effect on logout, or a portal effect on checkout).

```tsx
import { useGlide } from '@/components/glidecn';
import { useRouter } from 'next/navigation';

export function CheckoutButton() {
  const { setTransition } = useGlide();
  const router = useRouter();

  const handleComplete = () => {
    // Switch to circular-portal transition for this navigation
    setTransition('circular-portal');
    router.push('/success');
  };

  return <button onClick={handleComplete}>Place Order</button>;
}
```

---

### `config`

The fully merged configuration object containing resolved `duration`, `delay`, `ease`, `direction`, `stagger`, and `custom` data.

```tsx
export function DurationIndicator() {
  const { config } = useGlide();
  return <span>Current speed: {config.duration}s ({config.direction})</span>;
}
```

---

### `setConfig(overrides)`

Dynamically updates transition properties on the fly. You can pass partial updates (e.g. `{ duration: 0.2 }` or `{ direction: 'right' }`).

```tsx
import { useGlide } from '@/components/glidecn';

export function SpeedSelector() {
  const { setConfig } = useGlide();

  return (
    <div className="flex gap-2">
      <button onClick={() => setConfig({ duration: 0.2 })}>Fast (0.2s)</button>
      <button onClick={() => setConfig({ duration: 0.6 })}>Normal (0.6s)</button>
      <button onClick={() => setConfig({ duration: 1.2 })}>Cinematic (1.2s)</button>
    </div>
  );
}
```

---

### `animationState`

Tracks the lifecycle phase of the transition:
- `"idle"`: No animation running.
- `"exiting"`: Old route is playing its exit variants.
- `"entering"`: New route is animating into view.
- `"complete"`: Animation has finished.

```tsx
export function TransitionLoadingBar() {
  const { animationState } = useGlide();
  const isTransitioning = animationState === 'exiting' || animationState === 'entering';

  if (!isTransitioning) return null;
  return <div className="fixed top-0 left-0 right-0 h-1 bg-red-500 animate-pulse" />;
}
```

---

### `reducedMotion`

Boolean indicating whether OS-level reduced motion is active (or forced via Provider).

```tsx
export function MotionStatus() {
  const { reducedMotion } = useGlide();
  return <span>Reduced motion: {reducedMotion ? 'Enabled' : 'Disabled'}</span>;
}
```

---

### `transitionDefinition`

Provides direct access to the registered transition definition, including metadata (`displayName`, `category`, `description`) and Framer Motion variant builders.

```tsx
export function TransitionInfo() {
  const { transitionDefinition } = useGlide();
  if (!transitionDefinition) return null;

  return (
    <div>
      <h3>{transitionDefinition.metadata.displayName}</h3>
      <p>{transitionDefinition.metadata.description}</p>
    </div>
  );
}
```

## Practical Recipes

### Directional Wizard (Next vs Back)

```tsx title="components/StepControls.tsx"
import { useGlide } from '@/components/glidecn';
import { useRouter } from 'next/navigation';

export function StepControls({ step }: { step: number }) {
  const { setTransition, setConfig } = useGlide();
  const router = useRouter();

  const handleNext = () => {
    setTransition('slide');
    setConfig({ direction: 'left' });
    router.push(`/onboarding/step-${step + 1}`);
  };

  const handleBack = () => {
    setTransition('slide');
    setConfig({ direction: 'right' });
    router.push(`/onboarding/step-${step - 1}`);
  };

  return (
    <div className="flex gap-4">
      <button onClick={handleBack}>Back</button>
      <button onClick={handleNext}>Next</button>
    </div>
  );
}
```
