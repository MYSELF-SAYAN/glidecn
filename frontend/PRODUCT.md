# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Next.js 15, Turbopack, TailwindCSS, Framer Motion

## Users
Independent React developers and creative agencies building high-end interactive websites and applications.

## Product Purpose
Morphy provides a massive catalog of 33+ visually driven, scene-changing transitions. It eliminates the complex routing and AnimatePresence boilerplate traditionally required to build cinematic page transitions in React.

## Positioning
Built entirely on Framer Motion's optimized rendering pipeline, Morphy offers zero boilerplate for complex page transitions. It manages the freezing, unmounting, and scroll state automatically so developers can focus purely on motion storytelling.

## Operating Context
Developers dropping `<MorphyProvider>` into their Next.js layouts and wrapping pages in `<Page transition="slug">`. The documentation acts as an interactive showcase, catalog, and copy-paste CLI installation hub.

## Capabilities and Constraints
- 7 Distinct visual families (Spatial, Portal, Paper, Mask, Dynamic, Retro, Flow).
- Support for custom durations, delays, and directional parameters per page.

## Brand Commitments
- Primary brand color: Coral/Salmon (`#fa5c4f` / `brand-500`).
- Aesthetic: Strictly adhere to the premium Morphy layout patterns (heavy border-radius, nested glass backgrounds, detailed radial/linear gradients).
- Typography: Inter (Sans), Space Grotesk (Display), JetBrains Mono (Mono), Caveat (Cursive).

## Evidence on Hand
- Implementation of 33+ hero transitions and shader previews.
- Fully built custom documentation shell mirroring Morphy's premium layout architecture.

## Product Principles
1. **Visual Excellence First**: Every transition must feel cinematic, smooth, and highly polished.
2. **Developer Ergonomics**: Zero-boilerplate installation and usage via CLI and copy-paste prompts.
3. **Architectural Premium**: Honor the premium layout structure of Morphy to showcase the transitions effectively.
